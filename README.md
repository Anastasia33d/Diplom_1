# Проект юнит-тесты (1)
## Описание проекта
Данный проект представляет собой систему для создания и управления заказами бургеров. В проекте реализовано модульное тестирование основных компонентов с использованием JUnit и Mockito.
## Структура проекта
### Основные классы
- `Burger` - класс, представляющий бургер
- `Database` - класс для работы с базой данных ингредиентов
- `IngredientType` - enum для типов ингредиентов
- `Bun` - класс для булочек
- `Ingredient` - класс для ингредиентов
### Тестовые классы
- `BurgerTest` - тесты для класса Burger
- `IngredientTypeTest` - тесты для enum IngredientType
- `IngredientsTest` - тесты для класса Ingredient
- `BunTest` - тесты для класса Bun
### Запуск тестов
Для запуска тестов используйте команду:
```mvn clean test```
## Используемые технологии
- Java 11
- JUnit 4.13.2
- Mockito 5.4.0
- JaCoCo для анализа покрытия кода
## Отчет о покрытии
Для генерации отчета о покрытии кода используйте команду:
```mvn jacoco:report```
Отчет будет доступен в директории `target/site/jacoco/index.html`
